# Magic Phone Android — MVP 0.1.0

## چه چیزی ساخته شده؟

سورس اپ مستقل Android برای سیم‌کارت خود گوشی، بدون Windows، Phone Link و Magic Core.

- رابط کاربری فارسی، RTL و تیره با رنگ‌های ویولت/سایان.
- ورود فرمان متنی مانند `به J A N زنگ بزن` و `با مریم تماس بگیر`.
- دکمه فرمان گفتاری از طریق سرویس تشخیص گفتار موجود روی اندروید (ممکن است اینترنت بخواهد).
- جست‌وجوی مخاطب در دفترچه خود دستگاه (با اجازه کاربر)، پشتیبانی از نام دارای فاصله (`J A N`).
- انتخاب مخاطب از دفترچه بدون نیاز به مجوز خواندن همه مخاطبین، در صورت استفاده از سیستم انتخاب مخاطب.
- انتخاب شماره در صورت چند نتیجه و تأیید صریح نام و شماره.
- درخواست تماس با سیم‌کارت از طریق `ACTION_CALL` پس از تأیید و مجوز، یا `ACTION_DIAL` به عنوان مسیر جایگزین.

**مهم:** قابلیت شنیدن صدای تماس سلولی یا تزریق صدای ChatGPT به میکروفون تماس در این نسخه وجود ندارد. Android این مسیر را برای اپ‌های عادی محدود کرده است. این پروژه ادعای حل آن را ندارد. این اپ مستقیم به گفت‌وگوی فعلی ChatGPT متصل نیست. فقط یک فرمان‌پرداز محدود و محلی دارد.

## ساخت APK

۱. Android Studio را روی کامپیوتر نصب و پوشه `android/` را با گزینه Open باز کنید.
۲. JDK 17، Android SDK Platform 35 و Build Tools مربوطه را از Android Studio نصب/انتخاب کنید.
۳. Gradle Sync انجام بدهید. تنظیمات: Android Gradle Plugin `8.9.2` و Gradle `8.11.1`.
۴. مسیر **Build → Build Bundle(s) / APK(s) → Build APK(s)** را اجرا کنید.
۵. فایل APK خروجی Debug را روی سامسونگ نصب کنید.

> این بسته شامل `gradle-wrapper.properties` است. فایل `gradle-wrapper.jar` و خود SDK یا APK خروجی در این محیط موجود نیستند؛ می‌توانید در Android Studio Gradle را از توزیع Gradle انتخاب یا Wrapper را با `gradle wrapper --gradle-version 8.11.1` ایجاد کنید. پس از تولید Wrapper، `./gradlew assembleDebug` نیز قابل استفاده است.

## تست‌ها

- تست واقعی دستگاه و build کامل Android در این محیط اجرا نشده‌اند، چون Android SDK و Gradle نصب نیستند.
- `CallCommandParser.java` خالص است و با `javac` قابل تست است:

```bash
mkdir -p out
javac -encoding UTF-8 -d out app/src/main/java/site/magics/phone/CallCommandParser.java tools/ParserSmokeTest.java
java -cp out ParserSmokeTest
```

## دسترسی‌ها و امنیت

- `READ_CONTACTS` فقط هنگام جست‌وجو درخواست می‌شود.
- `CALL_PHONE` فقط پس از تأیید تماس درخواست می‌شود؛ برای `ACTION_DIAL` مجوز لازم نیست.
- شماره‌ها و اطلاعات مخاطبین به سرور ارسال یا در فایل ذخیره نمی‌شوند.
- هیچ ضبط تماس، Accessibility Service، شنود پس‌زمینه یا اجرای خودکار فرمان از راه دور وجود ندارد.
- در صورت دریافت فرمان ناشناخته، عدم تطابق یا چند شماره، تماس خودکار انجام نمی‌شود.
- برای هر تماس واقعی با مخاطب، درباره استفاده از دستیار هوشمند شفاف اطلاع‌رسانی و رضایت مناسب بگیرید.

## مراحل بعدی

۱. Build و نصب آزمایشی روی Samsung؛ تست فرمان متنی/گفتاری و شماره‌گیری واقعی.
۲. طراحی یک مسیر کنترل صوتی دوطرفه واقعی و سازگار با محدودیت‌های Android/اپراتور؛ برای تماس سلولی عادی هنوز راه‌حل عمومی تأییدشده‌ای نداریم.
۳. پس از تأیید مسیر صوتی و اجازه کاربر، طراحی موتور AI و اتصال امن به سرویس مکالمه؛ بدون نیاز اجباری به Magic Core.
