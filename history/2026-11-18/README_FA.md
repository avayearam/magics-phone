# سوابق Magic Phone — ۱۸ نوامبر ۲۰۲۶

این پوشه یک **Historical Snapshot** از مراحل انجام‌شده پروژه Magic Phone است و مبنای توسعه محصول نهایی از صفر محسوب نمی‌شود.

## محتویات

- `HANDOFF_FA.md` — هندآف کامل وضعیت پروژه در ۱۸ نوامبر ۲۰۲۶.
- `Magic-Phone-Source-Snapshot-v0.10-Bridge-v0.21.zip` — آرشیو سورس آپلودشده از آخرین بسته ارائه‌شده در این مرحله.
- `source-manifest.json` — فهرست فایل‌های داخل آرشیو و موارد عمداً حذف‌شده.

## نکته مهم نسخه‌ها

هندآف اصلی، Baseline آن مرحله را Chrome Extension v0.8 + Local Bridge v0.7 ثبت کرده است. بسته سورس جدیدترِ همین تاریخ، در `README_FA.md` خود نسخه Extension `0.10` و Bridge `0.21` را نشان می‌دهد. هر دو سند بدون بازنویسی تاریخی نگهداری شده‌اند تا سیر واقعی پروژه قابل پیگیری باشد.

## حریم خصوصی

از آرشیو تاریخی این موارد حذف شده‌اند:

- `bridge/contacts.json`
- `bridge/settings.json`
- `bridge/events.log`
- `bridge/__pycache__/`

بنابراین اطلاعات شخصی مخاطبین، Pairing Secret و Runtime Log وارد GitHub نشده‌اند.

## مسیر آینده

این بخش فقط **سوابق** است. در مرحله بعد، Magic Phone را به‌صورت یک محصول Windows Native از صفر طراحی و ساخته می‌کنیم و نصب‌کننده نهایی را جداگانه در مسیر انتشار قرار می‌دهیم.
